# Junk Log

An Android app for logging what you ate, with a daily reminder.

The whole interface lives in `android/app/src/main/assets/index.html`.
The Android layer around it handles the notification and the daily alarm.

The APK is built automatically by GitHub Actions on every push to `main`.
Open the **Actions** tab, click the newest run, and download **JunkLog-APK**
from the Artifacts section at the bottom.
